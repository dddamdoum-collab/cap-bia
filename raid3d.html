Raid 3D — prototype

Un seul niveau pour comparer avec le raid actuel.

Glisse le doigt sur la gauche de l'écran pour piloter Petit coup de doigt rapide sur le côté : tonneau ; vers le haut : looping. On esquive tout et on renvoie les tirs Bouton rond : tir (garde le doigt appuyé) Tir chargé : garde le doigt appuyé pour charger, l'avion tire seul (moins vite) pendant la charge ; seul le tir chargé perce les caisses blindées Pétard : détruit les obstacles et les groupes

Clavier : flèches, Espace (tir), Maj (chargé), C (pétard), Q / E (tonneau), R (looping)

Boost : double tir
